## 1. Claude Code: Getting Started ★

> **Featured · Beginner · ~1.5h required · ~5.6h with all courses**

For developers who want to go from zero to productive with Claude Code in their daily development workflow. Covers the agentic loop, installation across all environments, approval modes, the Explore → Plan → Code → Commit rhythm, and the customization basics that make Claude Code fit your team.

**Target audience:** Software developers, DevOps engineers, technical writers, anyone who writes code.

---

### Stage 1 — AI Foundations *(recommended)*

> Skip if you already have a working mental model of how LLMs work.

| Course | Priority | Hours | Why |
|---|---|---|---|
| [AI Capabilities and Limitations](https://anthropic.skilljar.com/ai-capabilities-and-limitations) | recommended | 0.25h | Builds the mental model that helps you diagnose unexpected Claude Code behavior instead of guessing. |
| [Claude 101](https://anthropic.skilljar.com/claude-101) | recommended | ~1h | Familiarizes you with Claude's interface, projects, artifacts, and skills — all of which carry over to Claude Code. |

### Stage 2 — Core Claude Code *(required)*

| Course | Priority | Hours | Why |
|---|---|---|---|
| [Claude Code 101](https://anthropic.skilljar.com/claude-code-101) | **required** | 1.5h | The primary introduction: agentic loop, installation in terminal/VS Code/JetBrains/Claude Desktop/web, approval modes, context management, CLAUDE.md, and customization fundamentals. |

### Stage 3 — Practical Workflows *(recommended)*

| Course | Priority | Hours | Why |
|---|---|---|---|
| [Claude Code in Action](https://anthropic.skilljar.com/claude-code-in-action) | recommended | 1.0h | Real-world workflow examples, hook implementations, MCP server and GitHub integration in practice. |

### Stage 4 — Customization & Advanced Features *(optional)*

| Course | Priority | Hours | Why |
|---|---|---|---|
| [Introduction to Agent Skills](https://anthropic.skilljar.com/introduction-to-agent-skills) | optional | ~0.5h | Build reusable markdown Skills that Claude Code applies automatically — eliminates repetitive prompting for team conventions. |
| [Introduction to Subagents](https://anthropic.skilljar.com/introduction-to-subagents) | optional | ~0.35h | Use subagents to delegate tasks and manage context in long or complex sessions. |
| [Introduction to Model Context Protocol](https://anthropic.skilljar.com/introduction-to-model-context-protocol) | optional | 1.0h | Connect Claude Code to external tools and data sources via MCP servers. |

## 2. Claude Code: Power User ★

> **Featured · Intermediate · ~1.85h required · ~11h with all courses**
> **Prerequisite:** [Claude Code: Getting Started](#1-claude-code-getting-started-)

For developers already using Claude Code who want to go deeper: build and share Skills, design subagent workflows, and master MCP to connect Claude to any external system.

**Target audience:** Software developers, platform engineers, team leads who have completed the Getting Started path.

---

### Stage 1 — Skills & Subagents *(required)*

| Course | Priority | Hours | Why |
|---|---|---|---|
| [Introduction to Agent Skills](https://anthropic.skilljar.com/introduction-to-agent-skills) | **required** | ~0.5h | Encode coding standards, review checklists, and workflow steps as Skills that activate automatically — eliminates repetitive prompting. |
| [Introduction to Subagents](https://anthropic.skilljar.com/introduction-to-subagents) | **required** | ~0.35h | Unlocks parallel work and clean context management for large or multi-phase tasks. |

### Stage 2 — MCP Integration *(required + recommended)*

| Course | Priority | Hours | Why |
|---|---|---|---|
| [Introduction to Model Context Protocol](https://anthropic.skilljar.com/introduction-to-model-context-protocol) | **required** | 1.0h | Foundation for wiring external tools into Claude Code — tools, resources, and prompts primitives for any integration. |
| [Model Context Protocol: Advanced Topics](https://anthropic.skilljar.com/model-context-protocol-advanced-topics) | recommended | 1.1h | Sampling, progress notifications, file access roots, and transport trade-offs for production MCP servers. |

### Stage 3 — Deep Dive: API & Agent Architectures *(optional)*

| Course | Priority | Hours | Why |
|---|---|---|---|
| [Building with the Claude API](https://anthropic.skilljar.com/claude-with-the-anthropic-api) | optional | 8.1h | Deep API knowledge (RAG, tool use, agent patterns, Computer Use) that informs advanced Claude Code integrations. |
